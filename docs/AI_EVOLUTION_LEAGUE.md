# 木木金金棋 · AI 种群进化联赛 V0.1

日期：2026-10-14。工作区：E:\CHATGPT\projects\oh-mumujinjin。
目标：把不同搜索、神经网络、探索参数放进真实棋局竞技场，选育更强且可部署在 GitHub Pages 的 AI。
现状：研究用。正式地狱 AI 没有替换；任何小样本“冠军”都不是实力晋级证据。

## 自动斗兽场

- 所有合法动作由 game.js 原始规则验证。只看旧 AI 的局部候选列表会误判远处的合法筑墙，本次已修正。
- 9x13 地图按照固定障碍数量分层：稀疏（0–5）、中等（6–11）、密集（12+）。
- 八名 AI 在每张地图两两配对、交换先后手，共 8 局/图；圆桌轮换七张地图后，每名 AI 与其余七名均各对战两局。
- 结果包含对手、执棋顺序、地图分类、胜负、终局、非法动作数量、行动 P50/P95。
- 地形规则本身是固定的传送门和冰面配置；当前“稀疏/中等/密集”只对障碍数量分组，不能声称已经在不同传送门坐标上做了实验。
- 联赛开发使用训练分组地图；最终必须另用真正未参与调参的独立保留地图进行推广判断。

## 遗传与变复杂

第一代实验根据开发集比赛成绩保留两个优秀个体，同时保留搜索系和神经网络系的强者，产生四名子代：
- PUCT 交叉变异：模拟次数、探索系数、神经策略先验比例、神经价值比例、两个网络的加权集成。
- 跨家族混合 AI：一部分预算交给搜索，另一部分预算交给网络指导的 PUCT；通过双方候选动作的静态评估及一步危险检测选择落子。
- 复杂度上限：每个 AI 最多两份网络，PUCT 4–24 次模拟，混合决策在同一个总思考预算内工作。
- 目前不直接混合神经元权重，因为不同网络隐藏单元不对齐；将来可以通过教师集成、知识蒸馏和继续训练产生小型子代模型。

第一轮 2 张密集地图、16 局 smoke：V1.1 搜索 3胜1负，V2 搜索 3胜1负，三种 PUCT/辅助策略多为 2胜2负，其余 1胜3负；非法行动 0。这个结果被标记为 experimental-only，样本和地形严重不足，不能宣布冠军。
已改善为从稀疏、中等、密集地图分层抽取。第一次进化输出为 training/league/population-proposal-g1.json。G1 混合体仍需实战验证。

## 绝不自动上线的晋级标准

- 在至少 500 张此前未用于选育的地图上，双方各执一方对战 1000 局，对冻结冠军的配对 Bootstrap 95% 区间下界高于 50%。
- 禁止非法走棋、漏掉直接取胜与必防着、循环判定错误；至少三类地形不能出现严重退化。
- 真机 GitHub Pages（Safari/Android/PC）的 Web Worker 搜索响应、内存、回合取消和地图工坊均要通过测试。
- 模型若不能胜过不使用网络的搜索器，就不晋级。神经元数量、参数量增加本身不能算作进步。
