# 木木金金棋国内好友联机：实施说明（2026-11-07）

## 目标
不开 VPN，在 GitHub Pages 首页点击好友联机，使用六位房间码和邀请链接两人实时下棋；保留现有 Cloudflare 国际联机后端与单机模式。

## 方案选择
用腾讯云 IM JavaScript SDK 的 Meeting 临时会议群承担国内消息传递。网页只包含公开 SDKAppID；匿名用户 UserSig 由腾讯 CloudBase 函数签发，保密密钥仅存在云端环境变量。先保留现有 Cloudflare 国际服务器为备用，Tencent IM 成功完成两部国内真机实测后才切默认。

## 约束
- 腾讯云 IM 免费体验版有应用/群组/用户数限制；新房间不应无限增长，房主退出时尝试解散无人的群。
- 房主负责规则校验（与目前 Cloudflare Durable Objects 的服务端权威不同），适合可信朋友娱乐局，不用于竞技排名与奖励。
- 房主离线时暂停对局；好友可重连、从群历史恢复棋局；房主恢复凭证后继续。
- 不能在 GitHub 仓库、网页和聊天输出 IM SecretKey/CloudBase 签名密钥。
- 尚未申请到 SDKAppID、CloudBase 环境和云端凭据前，绝不把国内联机标为已上线，也不改变 production 默认通道。
- 使用真实 IM SDK + 云端凭证双客户端测试才算完成上线；模拟 IM 只验工程逻辑。

## 实施步骤
- [ ] 建立腾讯云 IM 消息适配器和可注入 SDK 的测试，校验群码、角色、动作、重发、重连。
- [ ] 建立 CloudBase UserSig 签发云函数，限制来源、签名票据 TTL，环境变量管理，安全测试。
- [ ] 在现有好友房间 UI 接入“国内腾讯云/国际 Cloudflare”选择，首次按已部署配置决定，未配置时保留国际通道。
- [ ] 合成/固定 SDK 版本并验证 iPhone Safari 无语法错误及中文报错。
- [ ] 腾讯云 IM/CloudBase 帐号开通、控制台配置，部署后手机直连验收。
- [ ] 上线 GitHub Pages，验证国内无需 VPN 联机，保留回滚路径。

## 可验证的验收
相同六位码在两台不同设备连接，双方准备、出生点、行棋/筑墙/传送、胜负、认输、再战和断线恢复；不应把离线假房间称为联机成功。
