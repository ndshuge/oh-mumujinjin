# G3 · 木木金金棋 AI 生存淘汰联赛

日期：2026-10-14。目标：让策略/神经网络 AI 通过真实对局竞争、自然选择和受控遗传迭代；只保存比赛结果，不保存逐手棋谱。

## 本期已实现

- 初始种群 32 名：8 名规则搜索、8 名纯 PUCT、12 名神经网络 PUCT（24/48/64 神经元，以及此前 V2 网络）、4 名搜索＋网络混合 AI。
- 每代 3 个比赛日，分别选择稀疏/中密/密集障碍地图；每个比赛日 16 对匹配双方换手，共 32 局。每名 AI 每代对战 6 局，累计 96 局。
- 搜索与 PUCT 的墙钟时间预算一致，首届使用 180 ms/行动（研发初筛，而不是面向玩家的最终 1–5 秒预算）。双方交换执棋颜色，回合裁判只用 game.js 原始合法移动/筑墙规则。
- 原始结果只含比赛编号、地图类型和哈希、两名 AI、执棋位置、胜者、终局类型、总耗时、非法行动数；不含任何落子历史、每步状态或对话内容。
- 每代 32 名：保留 16 名，淘汰 16 名，利用生存 AI 的搜索深度/探索系数/模拟次数/神经策略权重/价值权重/网络集成比例生成 16 名下一代。策略融合不等于直接拼接不同模型神经元参数。
- 自动推进多代，不要求用户人工挑冠军。每代生成：成绩、临时排名、16 名淘汰名单、16 名后代父母和变异参数，以及 Markdown 战报。
- 少量地图和 6 局/AI 只能用于实验性淘汰，不能证明某个 AI 真的更强。正式“地狱冠军”晋级另用新地图双方换手至少 1000 局、Bootstrap 置信区间、零非法落子、浏览器 Web Worker 性能和真人体验验收。

## 运行方式

一键运行两代（每代 96 场，合计 192 场），每个比赛日最多 3 个独立 Node 进程：

    node training/g3/run-evolution.cjs population-g0.json 2 3 180 3 20261014 520

刷新成绩（自动输出易读 Markdown）：

    node training/g3/status.cjs 0 3 180 20261014

独立验证 JavaScript 语法：

    node --check training/g3/matchday.cjs
    node --check training/g3/select-and-breed.cjs

选育已内置于 run-evolution.cjs；不要手工覆盖旧比赛报告。程序失败后可读取 progress.json 诊断，已完成比赛日/单场结果会保留。

## 实际第一、第二代成绩（2026-10-14）

第零代完成 96 局，32 位参赛 AI 每位 6 局、3 张训练地图：第一名 G0-H02（混合搜索＋64 神经元）6胜0负；G0-S02、G0-S06 与 G0-P07 均 5胜1负；随后保留16名、淘汰16名，生成16名交叉后代。

第一代也完成 96 局：第一名 G1-SV15 搜索型与 G1-SV02 搜索型均 5胜1负；新生混合型 G1-CH13、G1-CH04 等取得4胜2负。再完成16名保留与16名淘汰、16名新生，生成第二代 population-g2.json。

目前已完成的两代合计 192 局，只能称为初筛，不是具有统计显著性的正式棋力提升；两代之间不能直接对比联赛得分率，因为对手变化。

## 奇怪变异和 V1.1 守擂赛

在第二代中引入10种有实际决策意义的变异：极端保守探索(c=0.35)、极端积极探索(c=2.9)、高网络策略先验、偏网络价值、24+64 两种神经元的集成、V2+V3 混合、25%搜索/75%神经路线、75%搜索/25%神经路线、双网络高探索、V3 深三层特殊搜索。另加入约18%概率的高方差但有界变异，淘汰仍根据真实比赛，不直接拼接不同网络神经元权重。

G3 与冻结 V1.1 对照使用 training/g3/champion-series.cjs，按相同地图与同样思考预算交换先手；第一轮14名候选，每位4张图8局，250ms/步，合计112局。原始结果和易读 Markdown 在 training/output/lab/g3/，不记录每步棋谱。此批图已被先前实验使用，不是新的盲测；不得自动上线。

## 后续升级方向

1. 将初筛对战数从每人 6 局提高到 20–40 局，覆盖不同强度的筑墙/传送/冰面局面，而非过早淘汰潜力 AI。
2. 保留历代最强冻结冠军，向下一代候选进行相同预算挑战，避免只会击败同代弱 AI 的策略形成虚假进化。
3. 对候选冠军另跑每回合 1–5 秒的高预算挑战，而不是把全体筛选都固定 180 毫秒，优先不牺牲真实玩家棋力。
4. 加入真正的神经网络权重继续训练、访问计数分布蒸馏和独立随机地图泛化；目前交叉的是推理策略与超参数，已有权重不会自动学习。
5. 研究 GUI 展示简洁的“第几代/排名/淘汰/继承树/冠军”战报，而不强制公开具体局面。
