## 产品目标

构建一个能让不同搜索、PUCT、24/48/64 隐藏单元神经网络以及搜索+神经混合体进行自然选择和参数杂交的本地训练实验室。玩家在 GitHub Pages 上仍面对稳定版本；不得根据小样本比赛直接覆盖正式 AI。

## 上一轮已验收的结果

14 个 G3 新策略共 112 场 V1.1 守擂赛，每个策略 4 张地图换手，8 局：
- Odd-Hawks（25%搜索预算/75%神经辅助的 V3 混合）：8胜0负。
- Odd-Tunnel（PUCT 极低探索系数）：6胜2负。
- Odd-Tortoise（搜索占 75% 的混合）：6胜2负。
- Odd-Dreamer（双神经网络混合）：6胜2负。
- Odd-Scout（极高探索系数）：5胜3负。
- 极端神经权重的 Odd-Mutant 与 Odd-Twins：各 0胜6负2和。

这些是**完全真实执行的开发赛成绩**，但每人只有8局，地图曾用于其他实验，不能认为任何候选已经具备可重复的高胜率。

## S4-1 100局/AI V1.1 守擂复测（后台真实运行）

- 参赛者 Odd-Hawks / Odd-Tunnel / Odd-Tortoise / Odd-Dreamer。
- 每位在相同的50张保留池地图上换手进行100局，每一步双方同样请求350ms计算预算，两个版本的实际耗时也记录在报告里。
- 总计划 400 局。地图来源于已用过的 S0 heldOut 池；**这仍是开发集复测，不是严格封闭盲测**。
- 每组输出 training/output/lab/challenge-ID-1310-50-b350.json，含胜负和、配对 Bootstrap 95%区间、非法行动数和 P95耗时。没有每步棋谱。
- 不夸大“p95<350ms”，搜索器实际可能比请求预算更慢，须以记录的 P95 为准。
- 只有得分和统计可靠的个体才值得启动新的1000局独立地图最终考试。

## S4-3 64 AI 进化（已启动比赛）

- 初始种群 64 名：16搜索、16纯PUCT、16神经网络PUCT、16搜索+神经网络混合。
- 每代6个比赛日，每天一张训练地图、所有64名双方换手，合计 384 局。每名 AI 每代12局。
- 地图按稀疏、中等、密集障碍分层选取，每档2张；传送门、冰面位置目前固定，地图变化主要是障碍布局。
- 第零代平均每步请求260ms计算预算，实际时间可能不同。多回合比较必须按相同请求预算及实测 P95 报告。
- 规则合法性判定直接使用 game.js，所有结果只有两位参赛 AI、胜者、地图类别和终局信息；**不保存逐手落子**。
- 每代：每个家族前8人保留，余8人淘汰；每个家族再繁殖8名后代，总共32保留、32淘汰、32新生。四类家族各16，不允许一个家族把其他家族完全挤走。
- 遗传：真实可运行的搜索引擎版本/搜索深度/模拟数/探索系数/网络融合权重/搜索时间占比。约25%子代进行高方差但合法的奇特变异，如探索系数极端值、网络模型切换、超重搜索或超重神经。
- 不把两个不同神经网络的权重张量直接拼接；目前进化的是推理策略与超参数，不等于完成了在线神经元强化学习。

## 后续正式比赛门槛

1. 每名晋级者必须挑战固定 V1.1，在从未参与选择和调参的新生成地图上至少500对换手局、总1000局，胜率的**按地图配对 Bootstrap 95%置信下界大于50%**，且非法行动0。
2. 必须记录三类地图的表现并避免极端崩溃，考虑角色先手偏差和延迟。
3. 手机、PC和安卓/iOS浏览器都必须使用 Web Worker，不得阻塞主线程；普通玩家目标1–2秒，关键回合最多5秒（实际性能需实测）。
4. 允许模型复杂度增长，但必须证明在相同计算预算下提升实战棋力；不应把参数量、训练局数或者内部对战平均得分当成实力提升。
5. 保留人工和历史冠军对抗试验，避免种群只适应自己的联赛生态。

注：大量自对弈棋谱仍由独立数据管线产生；**本轮G4联赛和V1.1挑战只存结果**，不保存逐手轨迹。
