# G5 → Human 持续施工与验收标准（2026-10-14）

## 最终目标与约束
在陌生地图、换手、公平思考时间和可核验规则下，击败精通《木木金金棋》的真实人类玩家。Human Gate 是真人实战，不是 AI 模拟对手。不得修改线上 GitHub Pages 或既有冻结基准；不得使用开发诊断地图作为最终盲测。工程应可中断恢复，保留真实证据，未完成不得标完成。

## 施工顺序
1. 六场重点败局复盘，校验与冻结原始对局结果一致；不一致需记录随机性与原因。
2. 反事实实验：从败局提取关键状态，逐个替换动作并检查合法性、对手最佳响应；只在开发地图调试。
3. 使用既有 self-play/神经网络管线训练新权重；保留模型版本、数据哈希与基线对比。
4. 新地图强基准、不同计算预算压力测试、无效动作回归；不通过则回到训练。
5. 构建本机 Human Challenge 页面/CLI 和证据记录；邀请真人高手挑战。

## 停止条件与报告
- 不覆盖旧日志、不在未授权情况下部署线上、不暴露密钥或私人信息。
- 每个 Gate 只在运行并检查产物后标 PASS；状态变更附日期、命令、结果。
- 人类参与无法自动替代；未参加真实比赛则 Human 只能标 READY 或 BLOCKED，绝不标 PASS。
