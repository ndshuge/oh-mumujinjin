# G6 AlphaZero Loop 自我进化学习阶段

## 目标

将 G1-G5 的进化竞技场升级为真正的自我学习闭环：

自我对弈 → 经验池 → Policy/Value 网络训练 → 新模型挑战冠军 → 胜者保留。

不替换冻结冠军，所有提升必须经过公平评测。

## G6.1 Self-play 数据管线

验收：
- 自对弈数据可自动生成
- 合法动作率 100%
- 数据包含地图、状态、策略分布、结果、版本哈希
- 训练集与隐藏测试地图无泄漏

## G6.2 Replay Buffer

验收：
- 支持增量写入
- 支持随机采样
- 支持去重和版本追踪
- 保存高价值失败案例

## G6.3 Policy/Value 学习

验收：
- 新模型权重真实变化
- Policy loss / Value loss 可追踪
- 独立地图棋力评测
- 不因训练导致冠军退化

## G6.4 自动晋级

- 双方换手

未证明提升不得上线。
