# 木木金金棋：在线确认落子、协议悔棋、违规状态修复（2026-11-09）

## 交互规则
好友联机：选定出生点、移动目标、筑墙位置、传送门去留，仅本机预览。点击“确认落子”才发送网络操作；“取消预览”不发消息。

悔棋只能由上一完整回合的落子者申请。申请者可撤回；另一位可以同意或拒绝。同意后统一回滚一回合；拒绝则棋局不动。待审批期间禁止新的落子。传送门进入和去留算一次完整回合。所有请求校验房间版本，防止过期响应再次回滚。

独立单机、人机玩法保持以前的立即操作与本地悔棋。

## 联机协议
Supabase 房间核心与 Cloudflare Durable Objects 共同使用 online-undo.mjs。接收者只获取 undoRequest、undoAvailableBy；私有 undoBefore 快照不向客户端公开。Cloudflare 房间快照保存在 Durable Objects；Supabase 仍采用房主权威机制，因此不能据此承诺房主离线后正常对局。

## BUG 排查与处理
截图显示木方在底边被石头、底边和墙隔绝。通过构造对应图形，验证了常规游戏核心引擎会拒绝这种封路。另发现本地电脑策略输入 playerMove 时缺乏终端合法性校验：独立回归测试曾证明不合法跨棋盘移动被执行，现终端入口重新从当时合法走法中匹配目标。旧存档恢复后会检测双方真实通路；非法旧状态先备份再重置对局。

无法凭静态图片确定用户那一局的全部历史操作，因此上面确认的是可复现的代码漏洞，不宣称已经完全回放过截图那一局。

## 已安排的验证
完整 Node 自动测试、Chrome 390px 移动入口测试、两个实际 Chrome 标签页的离线模拟在线 UI 交互。双标签测试真实渲染 Canvas 和操作栏，但模拟网络消息，不等同于中国大陆手机两端免 VPN 验收。该网络问题仍需单独验证。

## 发布与回滚
前端动态与静态脚本版本统一升级至 confirm-undo-20261109-r1，以防混用旧缓存。合并后 GitHub Pages 部署前端，online/worker.mjs 的变化触发 Cloudflare Worker 工作流；须逐一检查部署状态。撤销本次改动无需修改 Supabase 数据库。
