# 猜拳决定人机先后手（本地预览验收）

在已有 Map V2 独立分支基础上，新增人机开局猜拳弹窗。

**规则**：玩家点击石头/剪刀/布；电脑使用运行时随机源出拳（可验证为平手）；同拳重来。玩家赢时可选择先手（金方）或后手（木方）；电脑赢时选择先手（金方）。双方棋盘固定营地、金先行、筑墙与全部地图特殊规则保持不变。

**状态**：人机模式重开和难度切换会进入 rps 阶段；只有分配人类颜色之后才选起点。电脑自动选择其营地起点；当电脑执金时自动先走。选择后信息随存档保存。对局中对方回合与起点禁止人类抢操作。

**兼容**：此前本地双人模式无猜拳。旧人机记录缺少 humanSide 按历史玩家执金处理。电脑执木继续采用原难度策略；电脑执金支持默认最短路、高难度对抗候选、以及小迪通用 who 参数适配。该金侧高难度适配未经过原有模型棋力验证，不能把原难度标签视为跨执色实力一致。

**测试**：`node rps-regression.cjs`、`node rps-ai-gold-regression.cjs`、`node ai-regression.cjs`；此外执行既有完整 Map V2 回归。浏览器移动 390×844 与桌面 1280×920 截图在 `docs/map-v2-previews/rps-*.png`。

**发布边界**：此提交是仅供独立本地预览的 V2 分支，**未自动覆盖 Pages**。GitHub Pages 线上分支仍为不同版本，必须经过独立的差异评审、发布分支保护和线上验收后，才能发布。
