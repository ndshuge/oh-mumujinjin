## 1. S0 核验

- 生成器：`training/s0-sim.cjs`
- 独立棋谱重放：`training/replay-s0.cjs`
- 10,000 局全部以进入目标营地终止，合计 31 万余步。
- 墙体放置 17,117 次，传送 23,199 次，非法动作 0。
- 生成与重放分别检查动作合法性、目标位置与胜负标签。
- 训练集按标准化障碍坐标指纹分组，避免同一个障碍布局跨越训练和验证。
- 前端新增 3 次重复局面判和、120 手上限及悔棋恢复，`terminal-regression.cjs` 通过。
- **限制**：在本批自然自对弈中，没有覆盖重复局面实际发生的场景；该分支通过构造单元测试验证。

## 2. S1 搜索验收

- `training/policy.cjs` v2：40 个相对路径（包括加速带两段走法与传送选择）＋192 个墙体位置＝**232 动作索引**。
- v1 的 426 维最终落点编码有碰撞风险，已淘汰；v2 能区分行棋方向。
- `training/puct.cjs`：已修正从父节点视角回传价值的符号、对局面路径循环判和、置换表、预算停止。
- `training/s1-benchmark.cjs`：1000 个测试局面、200 张地图、6 simulations/局面；合法 100%；P50=70ms、P95=104ms、最大146ms。
- **限制**：浅层搜索样本置换表命中次数为 0，缓存加速仍需更深搜索证明；这些耗时均非手机实测。
- 两个玩家在“一步抵达终点”时的战术测试，48 simulations 均选择直接获胜的行动。

## 3. S2 数据质量

- 生成数据：`training/output/dataset-120-10000.jsonl`。
- 棋谱：`training/output/s0-records-120-10000.jsonl`。
- 训练样本 83,571，保留验证样本 19,111；抽样用于训练 12,000、验证 2,000。
- 唯一训练地图 7,162；唯一保留测试地图 1,785；交叉重复 0。
- 当前标签来自合法规则引擎上的目标引导行动与真实对局结果，**不是** AlphaZero 的大规模神经网络自对弈。
- 未包含训练集的原始对局文件不上传 GitHub Pages（保存在本机 `training/output`）。

## 4. S3 模型训练及消融

- 网络：纯 JS 实现的 1 隐藏层双头 MLP；地图障碍、棋子、墙体、轮到谁、可筑墙数和距离编码进入 548 维输入。
- 标签：232 维策略目标与 -1/0/+1 终局结果。
- 模型：`training/models/policy-value-v1.json`，约396KB。
- 按地图指纹分组验证，模型从未以这些地图的样本更新参数。
- 保留测试集：策略 top-1 **53.05%** vs 25.8% 频率基线；策略交叉熵 1.679 vs 2.387；价值 MSE 0.8626 vs 1.0011。
- 模型+PUCT 在另外 20 张地图的 40 个局面中均给出合法行动，非法动作搜索概率为零。
- **正式棋力测试不能通过**：
  - 网络完全替代原先验与价值评估：同地图换手 10 局，**0 胜 10 负**。
  - 保留规则价值估计、仅将模型作为 25% 策略先验：同样条件 10 局，**6 胜 4 负**。样本太小，不能证明棋力优势。
- 因此该模型作为实验权重保存；**暂不替换 GitHub Pages 的地狱 AI**。

## 5. 接受 / 拒绝准则

1. S0/S2：已满足既定数量、合法性、重放和不泄漏门槛。
2. S1：满足稳定性与离线延迟，但置换缓存的实际收益、深层搜索性能仍需后续验证。
3. S3：训练出真实权重，离线泛化指标通过；但是**对战晋级失败**，不能宣传已训练成“变态难度”或“超过玩家”。
4. 下一轮 S4 优先：更强的对抗棋谱标签（PUCT 访问分布）、至少 100 对换手测试、增加对局奖励与搜索深度，再重训模型。
5. S5/S6：只有跨地图对照的 95% 置信区间下界超过预设门槛、且手机端 P95 达标后才能投入正式地狱难度。

## 6. 增量验收：2026-10-14

- 新增 `training/acceptance.cjs`：统一读取 S0 重放、S1 性能、S2 样本和 S3 推理实验的报告，输出 10 项工程指标的机器可读结论。
- S0–S3 离线训练验收共 **10/10 检查通过**。其中 S3 的含义是权重训练、未见地图预测和合法性通过，不等于棋力晋级。
- 新增 `training/arena-judge.cjs`：以一张地图中换手的两局为一个样本，进行 5,000 次 Bootstrap 抽样，计算成对地图的 95% 区间。
- 网络策略先验权重 25%、规则价值权重 100% 时，24 张地图、48 局结果为 **25 胜 / 23 负，52.08%**。成对地图 Bootstrap 95% 区间 **41.67%～62.50%**，包含 50%，**不允许晋级**。
- 前五张地图曾用于选择混合比例，属于探索性验证；另设非重叠地图段以检查独立泛化。
- 额外保留布局：跳过前 200 张已保留地图，再取 12 张，双方换手 **24 局：9 胜 / 15 负，37.5%**，成对地图 Bootstrap 95% 区间 **20.83%～54.17%**，无显著优势。
- **最终裁决：S3 工程训练和离线指标通过，棋力晋级失败。** 后续必须更换训练/搜索策略，不得依靠调低检测门槛强行发布。

- GitHub 主网只部署经过验证的网页原有 AI；研究网络权重保存在项目训练目录，默认不上线。

```powershell
node training/s0-sim.cjs 1000 120 --records
node training/replay-s0.cjs s0-records-120-1000.jsonl
node training/s1-benchmark.cjs 1000 6
node training/s0-sim.cjs 10000 120 --dataset --records
node training/replay-s0.cjs s0-records-120-10000.jsonl
node training/train-model.cjs dataset-120-10000.jsonl 12000 2000
node training/model-verify.cjs 20
node training/s3-arena.cjs 5 6 0.25 0
node terminal-regression.cjs
```

生成器按传入种子运行；重新运行可得到新的地图批次。重训与完整基准会占用一定 CPU 时间及磁盘空间。
