# Map V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans; TDD, review and reproducible test gates apply.

**Goal:** 本地完整 V2 地图规则、工坊和随机生成。
**Architecture:** 游戏规则仍以既有 movementOptions/findPath 为权威，动态活动地图唯一来源；草稿隔离，保存/重放绑定指纹。
**Tech Stack:** Vanilla JS/Canvas、HTML、CSS、Node VM。
**Spec:** docs/superpowers/specs/2026-11-05-map-v2-design.md

## Global Constraints
- 9×13；营地和每方五墙不变；冰面方向和传送触发语义不变。
- 旧 V1 地图、分享链接和旧存档仍读；不改 AI 研究组或主分支；不发布。
## Review Focus
- 只换传送门配对即须换指纹。
- 入门选择不能免费连续传送。
- 旧 V1 存档与当前地图必须绑定。
- Pointer 拖动不能重复放置。
- 草稿非法状态不能保存或试玩。
