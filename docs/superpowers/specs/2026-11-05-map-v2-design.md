# 木木金金棋 Map V2 设计（2026-11-05）

目标：保持 9×13、固定双方营地、每方五堵墙及经典/进阶移动语义，支持四类地形动态配置、编辑、随机、验证、分享、旧地图迁移。

架构比较：全规则重写风险高（弃用）；仅扩展工坊按钮会造成显示/规则割裂（弃用）；**沿用 game.js 的真实路径搜索，将当前地图统一投影到可变地形，并将草稿隔离**（采用）。

V2 字段：version=2、rulesVersion、generatorVersion、name、seed、rocks、portals[{id,a,b}]、ice、boost。V1 只含障碍时恢复原三对门、五格冰、四格加速。指纹使用固定尺寸、地形排序、传送配对和规则版本计算 SHA-256，忽略名称。

验证时使用现有真实移动规则，对两种玩法中双方全部三个出生点进行可达性验证，保证可保存/试玩；编辑草稿可暂时未完成。安装地图要同步渲染、规则、AI 接口、存档绑定，地图切换清除对局历史。

随机使用版本化确定性 PRNG、有限重试，优先生成连续冰面；合法性与趣味评估分开，指标不当作胜率保证。
