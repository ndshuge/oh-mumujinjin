# Map V2 对称竞技随机与 AI 兼容性试验（2026-11-05）

目标：一键随机生成不明显偏袒金/木、可由完整规则执行且有合理移动选择的战场；只读接入既有已公开 AI 接口做实际合法动作/对局压力测试。不修改冻结权重、训练脚本或 B/C/GPT 研究环境。

现状：普通 randomMap 允许双方最短距离差最大 12，且传送/冰/加速无双边收益限制。独立训练引擎 training/train.cjs 仅 setRocks，在 Map V2 运行时若沿用该引擎，会读取旧版特殊格数组。浏览器小迪神经输入只有传送端点占用通道，缺配对关系。

采用方案：默认「均衡随机」使用 **180°旋转对称** 的完整特殊地形及障碍（映射 x→8-x,y→12-y），并确保门 A/B 的完整配对镜像；奇数个元素只能用中心格承担中轴配额（传送门为自对称一对，其两端互为旋转；冰面/加速/障碍为中心格）。保留旧版「自由随机」代码与发生版本，兼容旧种子复现。两种模式都需通过真实 findPath 双模式六起点验证、特殊地形可用性检查和有限重试。路径对称不能证明先手公平或策略胜率，必须补充色位交换对局统计，不把样本胜率作为合法性判据。

接口：新增 generateBalancedMap(seed,opts) 和 recreate/reproduceMap 兼容。记录生成器版本与策略 profile，避免旧图同种子变化；UI 一键随机使用竞技均衡模式，高级可选择自由模式。AI 外层加载 V2 规则引擎在**本工作树**运行候选算法，不复制训练数据、不编辑 AI、不可把测试结论回流到原创组。

验收：原 12 组测试、1000 张独立均衡随机地图、经典/进阶可达、地形 180°对称以及传送门镜像配对、同种子复现、真实对局中无非法行动、零出生软锁；报告双方交换位置的比赛结果与置信局限。
