# 非对称且公平的地图 — 2026-11-06

用户：所有地图都要公平且不要刻意中心对称。范围：内置随机对战、随机障碍、地图工坊生成、默认布局、自定义地图对战入口。保留历史地图指纹、V1/V2 存档及已进行对局。

设计选择：
1. 取消生成器采用180°配对位置的算法，换成无对称约束的独立抽样（重复随机候选 + 双规则验证）；保留原 v2-r2 算法只用于历史种子复现，不再用于新图生成。
2. 在两个玩法分别比较双方最佳通路成本（经典≤1格，进阶≤2格）、初始合法行动空间（每方≥3；总行动数差≤2）、传送门捷径（收益差≤3）、加速格有可用收益（≥60%），不接受明显的布局对称（偶然对称样本重抽）。这是一项可复验的公平指标，不等于承诺AI胜率50%。
3. 默认图公平审计，不符合则改为预选的经同一规则审计的非对称固定地图（固定 seed）。随机障碍同样遵守指标；地图工坊“自由随机”也按该指标生成。
4. 工坊可保存任意结构合法的地图作为草稿／分享（避免损坏既有作品），但使用“开始对局”时强制公平审查；如果不合格，提示可见的具体原因，拒绝安装为竞技地图。已开始的旧存档不中断，后续开新局重新校验；旧地图不直接重写。
5. 公平函数严格复用现有验证与地图指标，避免陷入无穷循环；候选生成超时保留可解释失败，不静默回退至劣质图。
6. 确保可复现：旧版 r2 继续逐位相同，新版 r3 用新的 seed+parameters 复现且指纹与UI一致。不要更改 AI 或核心游戏规则。
7. 验收：批量至少 100 个不同 seed + 多档参数、公平指标、非镜像分布、地图合法与 replay 一致；原有编辑、猜拳、AI、60局训练例与公开手机端棋盘验收。
