# 小克正式界面整合与移动端稳定性修复设计 — 2026-11-06

## 用户目标
游戏默认进入“与小克对战”的呈现状态，采用 Claude 橘色头像和只有符号/颜文字的对白；经典/进阶对应模型随后接入。当前严禁用中迪引擎伪装小克。
避免首次进入误显示“木木/小白”、双指网页缩放及偶发空棋盘。

## 验证到的缺陷
- 旧的本地游戏存档仅校验 variant/players/walls，没有校验 left/history 等；可复现 TypeError at game.js:712，导致 Canvas 完全空白 (pixel alpha 0)。
- 初始 HTML 显示木木/中迪；JS defer 脚本初始化前会闪现错误角色。
- viewport 允许浏览器缩放，触控层没有专门拦截双指捏合。
- 现有小克只在独立对话预览中，尚未进入实际对手选项、棋局头像及默认选择。

## 选择
1. 小克立即冒用中迪引擎：否决（会误导用户和模型评测）。
2. 小克出现为“可选且待接入”对手并默认选中，展示棋盘/角色但锁定下棋；保留中迪/小迪可完整对局。采用此方案。
3. 小克作为只有独立预览入口：不足以满足“全部接入”。

## 具体行为
- 首次进入/没有已进行中的对局：默认对手小克、模式经典、棋盘可见；若用户已有进行中的对局则恢复原局。
- 小克等待模型时显示清晰的未接入状态，无猜拳弹窗、无 AI 走子，不跳其他引擎；切换中迪/小迪马上恢复正常。
- UI 默认即是小克头像与符号短句，无木木闪现。点击头像更新短句；对局状态与对手可切换。
- 语音内容不含汉字或英文字母（只有状态标签可中文），减少动画遵从用户设置。
- 损坏的本地存档保留备份副本、加载默认合法棋局并不抛错；正确旧存档不得丢失。
- viewport 防双指缩放保留单指滚动；Firefox/桌面普通滚动不受影响。
- 屏幕窄、短、横屏和标准桌面布局能看见棋格；初始化失败时显示可理解的加载/重试提示，避免无解释的空白。
- 独立分支开发、验证，发布需按项目保护的合并门槛，不覆盖其他开发中的地图 V2。

## 验收
- Node 级字符和 DOM tests + CDP 实机尺寸首屏：存档正常、损坏、清空；小克默认/切中迪、小迪；Canvas 至少一个非透明像素。
- 源代码不存在小克自动回退中迪；触控反缩放 handler 注册并拦截双指而放行单指。
- 不触碰其他 worktree；不强制推送。
